# mintwasm

Mint CSV/TSV wasm tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/mintwasm/

## Install / run

```bash
git clone https://github.com/theworker02/mintwasm.git
cd mintwasm
node src/cli.js
node --test
```
